두 비밀번호는 서로 다르게 정합니다. 길고 남이 짐작하기 어려운 것으로 해 주세요.

함께 가꾸는 광양교육사랑 홈페이지입니다회원님이 올린 사진 한 장, 글 한 줄이 아이들의 오늘을 기록합니다. 어렵지 않습니다. 처음이시면 사용 설명서를 먼저 눌러 보세요. 한 장씩 넘기며 따라 할 수 있습니다.

📖 사용 설명서

광양교육사랑 홈페이지에 글·사진·자료를 올리는 방법을 한곳에 모았습니다. 처음이신 분은 위에서부터 차례로 읽어 주세요.

처음 들어오기소식·사진자료영상일정꼭 지킬 것안 될 때 임원이 하는 일

1. 처음 들어오기

  1. 홈페이지(광양교육사랑.kr)에서 글·사진 올리기 버튼을 누릅니다. 홈 화면 가운데와 맨 아래에 있습니다.
  2. 비밀번호를 넣고 들어가기를 누릅니다. 정회원은 정회원 비밀번호, 임원은 임원 비밀번호입니다.
  3. 위쪽 버튼에서 하고 싶은 일을 고릅니다.
  4. 다 했으면 오른쪽 위 나가기를 누릅니다. 같이 쓰는 컴퓨터에서는 꼭 눌러 주세요.
누가할 수 있는 일
정회원소식·사진 올리기, 자료 올리기, 일정 넣기
임원위의 일 + 지우기, 배너, 기본 정보, 회장단, 명부·비밀번호
올린 것은 1~2분 뒤에 홈페이지에 나옵니다. 바로 안 보이면 홈페이지에서 키보드 Ctrl + F5를 눌러 주세요. 휴대폰은 화면을 아래로 당겨 새로 고칩니다.

2. 소식·사진 올리기

행사 다녀온 이야기, 알리는 글을 올립니다. 사진을 함께 올리면 홈 화면 갤러리에도 저절로 나옵니다.

  1. 소식·사진 올리기를 누릅니다.
  2. 분류를 고릅니다. 행사 사진은 "활동", 행사 안내는 "행사", 알림은 "공지"입니다.
  3. 제목을 씁니다. 예: "환경 동요 부르기 대회 다녀왔습니다"
  4. 내용에 언제, 어디서, 누가 함께했는지 두세 줄 적습니다.
  5. 사진을 한 장 고릅니다. 휴대폰 사진 그대로 올려도 알맞게 줄여 줍니다.
  6. 올리기를 누르고 초록색 "올렸습니다"가 나올 때까지 기다립니다.
사진은 글 하나에 한 장입니다. 사진이 여러 장이면 글을 나누어 올려 주세요. 갤러리에 한 장씩 차례로 나옵니다.

3. 자료 올리기

계획서, 리플릿, 신청서 같은 파일을 자료실에 올립니다. 자료실은 누구나 볼 수 있습니다.

  1. 자료 올리기를 누릅니다.
  2. 분류를 고릅니다. 계획서·리플릿은 "행사자료", 빈 신청서는 "서식"입니다.
  3. 제목에 연도와 행사 이름을 넣습니다. 예: "2026 청소년 페스티벌 리플릿"
  4. 파일을 고릅니다. 한글(HWP), 엑셀, PDF, 사진 모두 됩니다. 파일 하나에 25MB까지입니다.
  5. 올리기를 누릅니다.

4. 영상 올리기

영상은 크기가 커서 홈페이지에 바로 올리기 어렵습니다. 유튜브에 먼저 올리고 주소를 붙여 넣습니다.

  1. 유튜브(youtube.com)에 로그인하고 만들기 → 동영상 업로드로 영상을 올립니다.
  2. 공개 상태는 일부 공개나 공개로 합니다. "비공개"로 하면 홈페이지에서 안 나옵니다.
  3. 영상 주소(https://youtu.be/…)를 복사합니다.
  4. 소식·사진 올리기나 자료 올리기의 유튜브 영상 주소 칸에 붙여 넣고 올립니다.
10~20초짜리 짧은 영상(25MB 이하)은 "자료 올리기"에서 파일로 바로 올려도 됩니다.

5. 행사 일정 넣기

  1. 일정 넣기를 누릅니다.
  2. 날짜를 고르고 행사 이름을 씁니다.
  3. 시간·장소를 씁니다. 예: "14:00 · 광양문화예술회관"
  4. 넣기를 누릅니다. 홈페이지 "행사 일정" 달력에 나옵니다.

6. 꼭 지킬 것

  • 아이들 사진: 얼굴이 크게 나온 사진은 보호자께 먼저 여쭤보고 올립니다. 우리 아이들을 지키는 일입니다.
  • 개인 정보: 이름·전화번호·주소·생년월일이 적힌 명단이나 신청서는 올리지 않습니다. 임원에게 따로 전해 주세요.
  • 남의 사진·음악: 인터넷에서 받은 사진, 가수의 노래는 올리지 않습니다. 우리가 직접 찍고 만든 것을 올립니다.
  • 비밀번호: 회원이 아닌 분께 알려 주지 않습니다. 단체 대화방에 올릴 때는 회원만 있는 방인지 확인합니다.
  • 잘못 올렸을 때: 정회원은 지울 수 없습니다. 임원에게 알려 주시면 지워 드립니다.

7. 안 될 때

이렇게 나오면이렇게 합니다
"비밀번호가 맞지 않습니다"한/영 키, Caps Lock을 확인하고 다시 넣습니다. 그래도 안 되면 임원에게 비밀번호를 물어봅니다.
"다른 사람이 방금 올려서 겹쳤습니다"올리기를 한 번 더 누릅니다.
"파일이 25MB보다 큽니다"영상이면 유튜브에 올리고 주소를 넣습니다. 문서면 PDF로 바꿔 크기를 줄입니다.
"열쇠가 맞지 않거나 기한이 지났습니다"대표 관리자에게 알려 주세요. 열쇠를 새로 만들어야 합니다.
올렸는데 홈페이지에 안 보임2분 기다린 뒤 홈페이지에서 Ctrl + F5를 누릅니다.
올리는 중에 멈춘 것 같음큰 파일은 1~2분 걸립니다. 창을 닫지 말고 기다립니다.

8. 임원이 하는 일

보기·지우기 — 잘못 올라온 소식, 자료, 일정을 지웁니다. 지운 것은 되돌리기 어려우니 한 번 더 살펴 주세요.

배너 — 회원 업체 배너 4자리(가로 600 × 세로 200)와 광고 배너 1자리(가로 1200 × 세로 200)에 그림을 넣습니다. 누르면 열릴 주소도 넣을 수 있습니다.

기본 정보 — 회장 인사말, 주소, 전화, 이메일, 회비, 후원 계좌를 고칩니다. 홈페이지의 노란 빈칸이 채워집니다.

회장단 — 지금 회장단과 역대 회장 명단을 고칩니다. 새 회장단이 취임하면 지금 회장님을 역대 회장 맨 아래 줄에 더하고, 위쪽 칸을 새 회장단으로 바꿉니다.

명부·비밀번호 — 회원 명부(엑셀)와 임원만 보는 자료를 잠가서 올립니다. 여기서 정회원 비밀번호와 임원 비밀번호도 새로 정합니다.

  • 명부 엑셀의 첫 줄은 "이름, 직책, 업체, 연락처" 같은 제목으로 둡니다. 생년월일과 집 주소는 뺍니다.
  • 올릴 때마다 전에 올린 명부와 임원 자료는 새것으로 바뀝니다. 계속 둘 자료는 다시 함께 골라 주세요.
  • 회원이 탈퇴하거나 임원이 바뀌면 비밀번호를 새로 정하고, 새 비밀번호를 따로 알려 줍니다.
비밀번호는 길게 정할수록 안전합니다. 모임 이름, 전화번호, 생일은 피해 주세요.

소식·사진 올리기

행사 사진이나 알리는 글을 올립니다. 올리면 "소식"에 나옵니다.

올리는 방법
  1. 분류를 고릅니다. 행사 사진은 "활동", 행사 안내는 "행사", 알림은 "공지"입니다.
  2. 제목을 씁니다. 예: "환경 동요 부르기 대회 다녀왔습니다"
  3. 내용에 언제, 어디서, 누가 함께했는지 두세 줄 적습니다. 짧아도 괜찮습니다.
  4. 사진을 한 장 고릅니다. 휴대폰 사진 그대로 올려도 됩니다.
  5. 영상이 있으면 유튜브 주소를 붙여 넣습니다.
  6. 초록색 올리기를 누르고, "올렸습니다"가 나올 때까지 기다립니다.

1~2분 뒤 홈페이지 "소식"에 나옵니다. 아이 얼굴이 크게 나온 사진은 보호자께 먼저 여쭤봐 주세요. 우리 아이들을 지키는 일입니다.

긴 영상은 유튜브에 올린 뒤 그 주소를 여기에 붙여 넣으면, 글 안에서 영상이 나옵니다.

큰 사진은 알맞은 크기로 줄여서 올립니다. 아이 얼굴이 나온 사진은 보호자 동의를 받은 것만 올려 주세요.

자료 올리기

문서, 사진, 짧은 영상·음원을 자료실에 올립니다.

올리는 방법
  1. 분류를 고릅니다. 계획서·리플릿은 "행사자료", 신청서 같은 빈 양식은 "서식"입니다.
  2. 제목을 씁니다. 나중에 찾기 쉽게 연도와 행사 이름을 넣어 주세요. 예: "2026 청소년 페스티벌 리플릿"
  3. 파일을 고릅니다. 한글(HWP), 엑셀, PDF, 사진 모두 됩니다.
  4. 긴 영상은 파일 대신 유튜브 주소를 넣습니다.
  5. 초록색 올리기를 누릅니다.

자료실은 누구나 볼 수 있습니다. 이름·전화번호·주소가 적힌 명단은 여기에 올리지 말고 임원에게 전해 주세요.

파일과 유튜브 주소 중 하나만 넣습니다. 긴 영상은 유튜브에 올리고 주소를 넣어 주세요.

회원의 주민번호·집 주소·전화번호가 적힌 파일은 올리지 마세요. 자료실은 누구나 볼 수 있습니다.

행사 일정 넣기

달력에 일정을 넣습니다.

넣는 방법
  1. 날짜를 고릅니다.
  2. 행사 이름을 씁니다. 예: "제11회 청소년 꿈과 끼 페스티벌"
  3. 시간·장소를 씁니다. 예: "14:00 · 광양문화예술회관"
  4. 초록색 넣기를 누릅니다.

넣어 두면 회원 모두가 달력에서 함께 봅니다. 날짜가 바뀌면 임원에게 알려 주세요.

올린 것 보기·지우기

잘못 올린 것을 지웁니다. 지우면 홈페이지에서 사라집니다.

지우는 방법
  1. 지울 것을 찾습니다. 소식, 자료실, 행사 일정 순서로 있습니다.
  2. 오른쪽 지우기를 누릅니다.
  3. "정말 지울까요?"가 나오면 한 번 더 확인하고 확인을 누릅니다.

지운 것은 되돌리기 어렵습니다. 회원이 정성껏 올린 글일 수 있으니, 지우기 전에 한 번 더 살펴 주세요.

배너

회원 업체 배너 4자리(가로 600×세로 200)와 광고 배너 1자리(가로 1200×세로 200)입니다.

배너 넣는 방법
  1. 넣을 자리를 고릅니다. 회원 업체는 1~4번, 외부 광고는 맨 아래 "광고 배너"입니다.
  2. 배너 그림을 고릅니다. 회원 업체는 가로 600 × 세로 200, 광고는 가로 1200 × 세로 200 이 알맞습니다.
  3. 업체 이름과 누르면 열릴 주소를 씁니다. 주소는 없어도 됩니다.
  4. 저장하기를 누릅니다.

빼고 싶으면 그 자리의 "배너 빼기"를 누릅니다. 모임을 도와주시는 분들의 얼굴이니 그림이 잘리지 않았는지 홈페이지에서 한 번 봐 주세요.

기본 정보

홈페이지의 노란 빈칸에 들어갈 내용입니다. 비워 두면 빈칸으로 보입니다.

고치는 방법
  1. 고칠 칸에 내용을 씁니다. 지금 홈페이지에 나오는 내용이 미리 들어 있습니다.
  2. 모르는 칸은 비워 둡니다. 나중에 채워도 됩니다.
  3. 맨 아래 저장하기를 누릅니다.

인사말은 줄을 바꿔 써도 그대로 나옵니다. 후원 계좌는 통장과 한 글자씩 맞춰 봐 주세요.

회장단

지금 회장단과 역대 회장 명단입니다.

고치는 방법
  1. 위쪽 네 칸에 지금 회장단(대수, 연도, 회장 이름, 취임일)을 씁니다.
  2. 임원은 한 줄에 한 분씩 "직책, 이름"으로 씁니다. 예: "부회장, 김태우"
  3. 역대 회장은 한 줄에 한 분씩 "대수, 이름, 연도"로 씁니다. 이름을 모르면 대수만 써 둡니다.
  4. 저장하기를 누릅니다.

새 회장단이 취임하면 지금 회장님을 역대 회장 맨 아래 줄에 더하고, 위쪽 칸을 새 회장단으로 바꿔 주세요. 모임이 걸어온 길을 잇는 일입니다.

회원 명부 · 임원 자료 · 비밀번호

명부와 임원 전용 자료를 새로 잠가서 올립니다. 여기서 정한 비밀번호가 새 정회원·임원 비밀번호가 됩니다. 전에 올린 명부와 임원 자료는 새것으로 바뀝니다.

올리는 방법
  1. 회원 명부 엑셀을 고릅니다. 첫 줄은 "이름, 직책, 업체, 연락처" 같은 제목이어야 합니다.
  2. 임원 전용 자료를 고릅니다. 시나리오, 회의록처럼 임원만 볼 것입니다. 없으면 안 골라도 됩니다.
  3. 새 정회원 비밀번호와 새 임원 비밀번호를 정합니다. 서로 다르게, 길게 정합니다.
  4. 잠가서 올리기를 누릅니다.
  5. 새 비밀번호를 회원과 임원에게 따로 알려 줍니다.
